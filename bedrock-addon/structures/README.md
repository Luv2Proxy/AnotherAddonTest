# Sky Archipelago Structure Pack

This directory contains the data-driven structure layer used by the island generator.

The generator expects these IDs:

- `sky_archipelago:village`
- `sky_archipelago:hamlet`
- `sky_archipelago:monument`

The first two are Jigsaw structure starts. `monument` is a normal `.mcstructure` template.

The actual `.mcstructure` binaries must be exported from Bedrock worlds (or generated by Structure Blocks) because they are binary NBT files and cannot be safely fabricated as text. The JSON Jigsaw pools in this directory are complete and provide deterministic, weighted assembly rules around those templates.
